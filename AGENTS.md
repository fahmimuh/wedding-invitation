# Project instructions

Do not invoke Superpowers skills for work in this project.

## App entrypoint and architecture

- `index.html` is the application entrypoint. It contains the invitation markup, styles, and page behavior.
- `src/main.js` is the Vite module entrypoint and currently only marks the document with `data-app="wedding-invitation"`.
- `vite.config.js` configures the Vite development server on port `4173` and builds for `es2020`.

## Commands and scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

`package.json` defines only `dev`, `build`, and `preview`. There are no test, lint, or typecheck scripts.

## Focused validation

- Run `npm run build` after source changes; it produces the production bundle in `dist/`.
- Use `npm run dev` and open `http://localhost:4173` for focused browser validation.
- Run `git diff --check` before completing changes.

## Apps Script deployment and configuration ownership

- `apps-script/Code.gs` owns the Google Apps Script RSVP endpoint and its spreadsheet/sheet configuration.
- The Apps Script deployment is a Web app. Its deployment URL is configured as `RSVP_API_URL` near the top of `index.html`.
- Keep spreadsheet IDs, deployment URLs, and other credentials out of documentation and commits unless explicitly required.

## Generated files

- `dist/` is generated by `npm run build` and is ignored by Git. Edit source files, not generated output.

## GitHub Pages deployment

- `.github/workflows/pages.yml` deploys the site after every push to `main` and also supports `workflow_dispatch`.
- The workflow runs `npm ci`, runs `npm run build`, uploads `dist/`, and deploys it with GitHub Pages.
